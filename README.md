# شات النسر — Full Stack

## تشغيل محلي
1. ثبّت Node.js 18+.
2. افتح الطرفية داخل المجلد.
3. نفّذ: `npm install`
4. نفّذ: `npm start`
5. افتح: `http://localhost:3000`

## ما يعمل فعلياً
- Node.js + Express
- Socket.IO للرسائل الفورية
- SQLite لحفظ المستخدمين والرسائل
- غرف متعددة
- قائمة المتصلين لحظياً
- حفظ آخر 100 رسالة لكل غرفة
- تغيير الاسم
- الوضع الليلي

## للنشر
ارفع المشروع إلى أي استضافة Node.js تدعم WebSocket، ثم استخدم `npm install` و`npm start`. اضبط `PORT` حسب مزود الاستضافة، ويمكن وضع `DB_PATH` لمسار قاعدة البيانات.

## ملاحظات الإنتاج
قبل فتح الموقع للعامة أضف مصادقة حقيقية، rate limiting، حماية XSS/CSRF، نظام إشراف وصلاحيات، نسخاً احتياطية لقاعدة البيانات، وتخزيناً خارجياً للصور والملفات.


ملفات النشر الإضافية: `render.yaml`, `railway.json`, `Dockerfile`, `.dockerignore`, `.env.example`, `DEPLOY.md`.
